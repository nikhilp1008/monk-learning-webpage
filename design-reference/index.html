Q · Chemistry · Organic

Predict the major product when 2-bromobutane reacts with alcoholic KOH, and name the mechanism.

DRONA EXPLAINS

Alcoholic KOH is a strong base → it favours elimination, not substitution.

CH₃–CHBr–CH₂–CH₃ → CH₃–CH=CH–CH₃ + KBr + H₂O

Major product: but-2-ene — Saytzeff, the more substituted alkene wins.

mechanism → E2, base pulls β-hydrogen as Br leaves.

Drill the concepts, then take the real thing.
